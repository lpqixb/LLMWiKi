# 知识库与 RAG

## 定义

知识库是按特定组织方式存储、可供 AI 系统快速检索和调用的结构化或非结构化信息集合。来源：[[raw/2026-11-13-什么是知识库与 RAG（检索增强生成）]]

检索增强生成（RAG）是在生成内容前先从知识库检索相关信息，并将其作为上下文提供给生成模型的技术模式。来源：[[raw/2026-11-13-什么是知识库与 RAG（检索增强生成）]]

## 文档所述的典型流程

1. 将数据源接入知识库，对文档分块并通过嵌入模型转化为向量后存储。来源：[[raw/2026-11-13-什么是知识库与 RAG（检索增强生成）]]
2. 将用户问题转化为向量，并检索相似的知识片段。来源：[[raw/2026-11-13-什么是知识库与 RAG（检索增强生成）]]
3. 把问题和检索到的上下文交给 LLM 生成回答，并记录所引用的来源。来源：[[raw/2026-11-13-什么是知识库与 RAG（检索增强生成）]]

## 数据类型与应用

该文列举的知识库来源包括文本文档、结构化数据、网页与多媒体、实时 API 数据和企业系统数据。来源：[[raw/2026-11-13-什么是知识库与 RAG（检索增强生成）]]

文档列举的应用包括企业客服、医疗决策支持、法律合规检查、文献综述、产品推荐和内部知识共享。来源：[[raw/2026-11-13-什么是知识库与 RAG（检索增强生成）]]

## 质量与边界

该文指出，过时、重复或低质量资料会影响回答质量；检索相关性、隐私保护和规模成本也是持续挑战。来源：[[raw/2026-11-13-什么是知识库与 RAG（检索增强生成）]]

## 与本知识库的关系

本库以 Markdown 页面、来源链接和人工可读索引组织知识，而非实现向量检索管线。这是对当前仓库结构的描述；是否需要引入 RAG 应取决于资料规模、检索需求与维护成本，现有资料不足以给出通用结论。
