# DeepSeek Harness

> **限定**：以下信息来自接入教程文档，未独立调研产品全貌。

## 概述

DeepSeek Harness 是 DeepSeek 推出的桌面端 AI 应用，支持 macOS（Apple 芯片，macOS 13+）和 Windows。支持通过自定义模型 API 接入第三方 OpenAI 兼容服务。来源：[[raw/2026-11-14-DeepSeek Harness 接入 TokenAge 简明教程]]

## 关键信息

- **官网**：https://www.deepseek.com/harness/
- **下载页**：https://www.deepseek.com/zh/download/
- **平台支持**：macOS（Apple 芯片，macOS 13+）、Windows
- **第三方接入**：通过设置 → 模型 → 添加模型提供商 → 自定义模型 API，填写 Base URL（如 `/v1`）、API 协议（OpenAI Chat Completions）、密钥和模型 ID。来源：[[raw/2026-11-14-DeepSeek Harness 接入 TokenAge 简明教程]]
