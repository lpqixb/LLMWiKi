# 附件与图片（Assets）

将文档的附件、图片、图表、PDF 及其他非 Markdown 资源存放在此目录。

## 使用规则

- 使用可读且稳定的文件名，例如 `2026-11-13-agent-architecture.png`。
- 图片或附件应在使用它的 Markdown 页面中通过 Obsidian 嵌入语法引用，例如 `![[assets/2026-11-13-agent-architecture.png]]`。
- 若资源来自外部，请在关联的 `raw/` 资料或 Wiki 页面记录其原始 URL、作者、日期和用途。
- `assets/` 是资源存放处；从图片或附件得出的事实仍需在 Wiki 中标注可追溯来源。
