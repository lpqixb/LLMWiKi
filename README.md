# LLM Wiki

一个由 LLM Agent 增量“编译”的 Obsidian 知识库。

## 开始使用

1. 把一份待研究资料放入 `raw/`，不要在摄取后修改它。
2. 让我“摄取 `raw/<文件名>`”。
3. 从 [[wiki/index]] 浏览来源摘要、概念页、实体页与专题综合。
4. 定期让我“巡检 Wiki”，检查断链、遗漏索引、冲突和无来源陈述。

## 目录

- `raw/`：不可变的原始资料与出处。
- `wiki/`：AI 维护的长期知识与导航。
- `output/`：报告、问答等一次性输出。
- `templates/`：来源摘要和知识页模板。
- `AGENTS.md`：Agent 必须遵守的知识库编译规则。
